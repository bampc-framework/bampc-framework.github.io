Do My Samples Help?

Compute Budget Allocation for Real-World Sampling-Based MPC in Contact-Rich Manipulation

A systematic study of where a finite real-time simulation budget should go: control exploration, state uncertainty, dynamics uncertainty, or temporal alignment.

Read the overviewPaper · under review
TL;DR

More samples are not automatically better. The strongest allocation depends on the dominant sim-to-real error: state ensembles help under visual occlusion, while temporal alignment matters most for fast rolling dynamics.

Abstract

A finite budget. Four competing ways to spend it.

GPU physics makes sampling-based model predictive control practical for contact-rich manipulation, but the number of rollouts that fit inside a real-time control cycle remains finite. Those samples can explore more controls, represent state or dynamics uncertainty, or support better temporal alignment between simulation and the real system.

BAMPC makes these allocations directly comparable in a common MuJoCo Warp planning and deployment stack. Across contact-rich manipulation studies, the results show that there is no universally best allocation: compute should target the dominant source of sim-to-real error for the task at hand.

Framework

One stack, explicit trade-offs.

Every candidate is evaluated in a shared flattened rollout batch, allowing control candidates and uncertainty realizations to compete for exactly the same real-time simulation budget.

Experiments

Different errors reward different allocations.

The experiments isolate the dominant failure mode, then compare alternative uses of the same finite rollout budget.

01 · Push-to-Track

Represent the state when vision becomes uncertain.

A moving target forces sustained pushing and repeated visual occlusion. Evaluating every candidate across a belief ensemble reduces position error for both CEM and Predictive Sampling, despite leaving fewer samples for distinct controls.

  • Dominant error: object-pose uncertainty
  • Best allocation: moderate state ensemble
  • Aggregation: empirical mean

02 · Balance-to-Track

Align time when the dynamics move fast.

Small inconsistencies in an initialized rolling state quickly become large trajectory errors. Settling the rollout state and accounting for control latency outperform spending the saved compute on more candidates or more frequent replanning.

  • Dominant error: temporal misalignment
  • Best allocation: settling and forward prediction
  • Result: bounded tracking over a two-minute run

State uncertainty ablations

More uncertainty is not always better.

Increasing the number of state realizations generally helps, but with diminishing returns. An intermediate belief width performs best; excessively narrow or wide beliefs both increase error.

The useful question is not “How many samples can we run?” but “Which mismatch should those samples represent?”

Takeaway

No allocation wins everywhere.

State uncertainty is valuable when perception dominates. Temporal alignment is decisive when unobserved fast dynamics make the rollout state inconsistent. Dynamics randomization is useful when physics mismatch is truly the limiting factor—not as a universal default.
